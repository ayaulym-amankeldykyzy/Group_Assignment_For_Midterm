# PAWHAVEN – Midterm Project

PAWHAVEN is a responsive pet shop and pet adoption web platform developed by the SE-2504 team.

## Team Members and Page Responsibilities
- Miras Kamaladin — Home (index.html) and Shop (shop.html)
- Ayaulym Amankeldykyzy — Our Pets (pets.html) and Adoption (adoption.html)
- Dias Aibekuly — About Us (about.html) and Contact (contact.html)

## Technologies and Styling
- HTML5: Semantic web structure (header, nav, main, section, footer).
- Bootstrap 5.3.3 (CDN): Primary framework for layout, responsive navigation, utility classes, and components (Cards, Carousel, Modal, Forms).
- Embedded and Inline CSS: Custom styling, colors, and layout adjustments embedded directly within the HTML templates to complement the Bootstrap framework.
- Flexbox and CSS Grid: Layout structures built using Bootstrap's grid system.

## Responsive Design
- Built using a Bootstrap-first responsive architecture with breakpoints (col-12, col-md-6, col-lg-4, col-lg-3, col-xl-2).
- Responsive navbar with a toggle collapse component for mobile devices.
- Images utilize responsive styling to prevent overflow on smaller screens.
- Interactive Bootstrap Carousel implemented on the Our Pets page.

## Project Pages
- index.html — Home page with featured banners and announcements.
- shop.html — E-commerce page for pet food, accessories, and supplies.
- pets.html — Interactive gallery showcasing pets available for adoption.
- adoption.html — Adoption process guide and application details.
- about.html — Team story, mission statement, and background.
- contact.html — Contact form, location information, and social links.

## Running Locally
Open any .html file (such as index.html) directly in any modern browser, or launch the root folder using a local web server.
